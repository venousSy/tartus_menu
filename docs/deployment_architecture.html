Docker Compose Services
Service Image Port Role
nginx nginx:alpine 80, 443 Reverse proxy + SSL termination
backend custom Django 8000 (int.) Django + Gunicorn + DRF API
frontend custom Next.js 3000 (int.) Next.js App Router (PWA + Dashboard)
db postgres:16-alpine 5432 (int.) PostgreSQL database
backup custom cron — Daily pg_dump → upload to Cloudflare R2
CI/CD Pipeline — GitHub Actions
📝 git push → main
→
GitHub Actions triggers workflow
1 Run Django tests (pytest)
2 Build Docker images (backend + frontend)
3 SSH into VPS
4 docker-compose pull && docker-compose up -d
5 python manage.py migrate
